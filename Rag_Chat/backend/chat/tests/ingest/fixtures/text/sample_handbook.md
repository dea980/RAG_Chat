# Galaxy S25 사용 설명서 (요약)

> 출처: gsmarena.com / wikipedia (2025-02-07 출시 기준)

## 1. 개요

Galaxy S25 는 삼성전자가 2025년에 출시한 플래그십 스마트폰이다.

## 2. 주요 사양

### 2.1 디스플레이

6.2인치 Dynamic LTPO AMOLED 2X, 1080 x 2340 해상도, 120Hz 주사율, 피크 밝기 2600 nits 를 지원한다.

### 2.2 카메라

50MP f/1.8 메인 카메라 (OIS), 10MP 3배 망원, 12MP 초광각으로 구성된다. 8K@30fps 동영상 녹화를 지원한다.

### 2.3 배터리

4000mAh 용량의 배터리를 내장하며 25W 유선 (PD3.0) 과 15W Qi2 무선 충전을 지원한다.

## 3. 시작하기

### 3.1 SIM 카드 설치

SIM 트레이 핀을 사용하여 Nano-SIM 슬롯을 연다. 국제판은 듀얼 SIM + 듀얼 eSIM 을 지원한다.

### 3.2 전원 켜기

측면 버튼을 3초간 길게 누르면 전원이 켜진다.

## 4. 문제 해결

기기가 응답하지 않을 경우 측면 버튼과 음량 작게 버튼을 7초 이상 길게 누르면 강제 재시작된다.
