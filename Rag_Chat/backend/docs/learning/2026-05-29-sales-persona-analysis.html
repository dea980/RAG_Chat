2026-05-29 RAG 챗봇 사용자 정의 관련: IR 개선 plan

삼성 모바일부 영업 = 동질 집단이 아니다. 매장직·B2B·본사 기획·외판이 모두 다른 환경에서 다른 정보를 다르게 빠르게 요구한다. RAG 챗봇은 한 종류의 답이 아니라 페르소나별 정보 우선순위 를 알아야 한다.

⚠ 작업 가설. 아래는 공개 정보 + 일반 영업 조직 지식 기반 가설이다. 실제 사내 인터뷰 데이터 없음. 영업팀과 합 맞춘 후 보정 필요.

비유응급실 / 가정의학과 / 산부인과

같은 "환자" 도 어떤 의사가 보느냐에 따라 묻는 것이 다르다:

  • 응급실: "지금 당장 죽나? 뭘 끊어야 하나?" — 속도 우선, 정답 1개
  • 가정의학과: "장기 관리. 다음 약은? 식이는?" — 맥락 우선, 옵션 비교
  • 산부인과: "임신 차원 정보. 다른 과 안 봐도 됨" — 도메인 좁고 깊음
매핑. 매장직 = 응급실 (고객 앞에서 30초). B2B = 가정의학과 (제안서, 옵션 비교). 본사 기획 = 산부인과 (좁고 깊은 분석). 같은 챗봇이 셋에 같은 답 = 누구도 만족시키지 못함.

CHK가설 보정 절차

이 문서는 가설 이다. 다음 절차로 보정:

  1. 사내 인터뷰 5명 × 페르소나 — 30분씩, 자주 받는 질문 top 10
  2. 수집된 100개 질문 → dataset 의 ground truth 로 흡수
  3. 분포·난이도 가중치 재조정
  4. 3개월 후 실제 챗봇 로그 로 분포 검증
핵심. 인터뷰 없이는 페르소나 비중 (50/25/15/10) 은 추측 이다.

EX연습 문제

문제 1 쉬움

P1 매장 직원과 P3 본사 기획 모두 "S25 카메라" 라고 질문했다. 같은 답이 맞나? 다르다면 어떻게 다르게 답해야 하나? 2개 이상 차이점.

힌트. 답변 길이 · 답변 톤 · 포함 정보 (가격 vs 벤치마크).

문제 2 중간

P2 B2B 영업이 "Tab S10 Ultra 100대 도입 견적" 이라고 물었다. 우리 corpus 에는 공개 USD 가격만 있다. RAG 가 어떻게 응답해야 하는가? 답변 본문 + 메타 정보 (citation · disclaimer) 를 1~2 문장씩.

힌트. "기업 견적은 공개 단가 외 변수가 큼. 본 가격은 공개 시작가 기준" 패턴.

문제 3 어려움

10K dataset 중 P1 매장 5000 질문 평균 MRR = 0.92, 평균 답변 길이 8 문장. production 출시하면 매장 직원 만족도는? MRR 만 좋아진 게 만족도와 직결되지 않는 이유 3가지.

힌트. P1 답변 환경 (고객 앞) · 정보 과잉 비용 · latency · 음성 변환 가능성.
