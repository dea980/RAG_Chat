# 삼성 모바일부 영업 페르소나 분석 — RAG 챗봇 사용자 정의

> 이 문서는 [IR 개선 plan](./2026-05-29-ir-improvement-plan.md) 의 전제 조건이다.
> "누가 무엇을 묻는가" 가 정해지면 그 다음에 corpus 수집 범위와 10K eval
> dataset 설계가 결정된다. 그 전에는 모든 IR 튜닝이 빈 곳을 겨냥하게 된다.

## 한 줄 요약

**삼성 모바일부 영업 = 동질 집단이 아니다.** 매장직, B2B, 본사 기획, 외판이 모두
다른 환경에서 다른 정보를 다르게 빠르게 요구한다. RAG 챗봇은 한 종류의 답이
아니라 **페르소나별 정보 우선순위** 를 알아야 한다. 이 문서는 4 페르소나를
정의하고, 그에 따라 corpus 와 dataset 이 무엇을 채워야 하는지 도출한다.

---

## 1. 비유 — 응급실 의사 vs 가정의학과 vs 산부인과

같은 "환자" 도 어떤 의사가 보느냐에 따라 묻는 것이 다르다:

- **응급실:** "지금 당장 죽나? 뭘 끊어야 하나?" — 속도 우선, 정답 1개
- **가정의학과:** "장기 관리. 다음 약은? 식이는?" — 맥락 우선, 옵션 비교
- **산부인과:** "임신 차원 정보. 다른 과는 안 봐도 됨" — 도메인 좁고 깊음

영업도 똑같다. **매장직 = 응급실** (고객 앞에서 30초 안에 답), **B2B = 가정의학과**
(긴 제안서, 옵션 비교), **본사 기획 = 산부인과** (좁고 깊은 분석). 같은 챗봇이
세 명에게 같은 답을 주면 누구도 만족시키지 못한다.

---

## 2. 왜 이게 필요한가 — 페르소나 무시의 비용

| 측면 | 페르소나 무시 (현재 상태) | 페르소나 명시 후 |
|---|---|---|
| corpus 우선순위 | "스펙 다 넣자" 식 무차별 | 매장직 → 정가/할부/색상, B2B → DeX/관리/단가 |
| dataset 질문 분포 | 임의 — 작성자가 corpus 보고 작성 | 페르소나별 비중 (예: 매장 50%, B2B 30%) |
| 평가 metric 가중치 | MRR 평균 (모든 질문 동등) | 매장직 응답 latency 가중치 ↑ |
| chunk metadata 설계 | category 만 | category + audience_tier (b2c/b2b/internal) |
| 답변 톤 (prompt) | 일률 친근체 | 매장직 = 짧고 명료, B2B = 격식·전문, 본사 = 데이터 위주 |
| 우선 deferred 기능 | 모호 | "결합 할인 계산기" vs "경쟁사 비교표" 명확 |

**한 줄:** 페르소나 명시 = corpus 선별 + dataset 균형 + metric 가중치 한꺼번에 결정.

## 3. 4 페르소나 정의

> **솔직 고지.** 아래는 공개 정보 + 일반적 영업 조직 지식 기반 *작업 가설* 이다.
> 실제 인터뷰 데이터 없음. 이 문서가 잘못된 가정 위에 서 있을 수 있으므로
> 영업팀과 합 맞춰 보정해야 한다. "작업 가설" 표시는 *italic* 으로 표기.

### P1 — 매장 직원 (오프라인 매장 · 디지털프라자 · 양판점 진열)

| 항목 | 내용 |
|---|---|
| 환경 | *고객 응대 중. 시간 압박 30초~2분. 옆에 단말기 직접 시연 가능.* |
| 자주 받는 질문 | "이거 얼마?", "할부 가능?", "iPhone 보다 좋은 점?", "재고 색상?", "이전 모델 차이?" |
| **가장 필요한 정보** | 자급제 가격, 통신사별 출고가, 결합 할인, 색상·재고, 1줄 셀링 포인트 |
| 답변 길이 | **짧을수록 좋음** (1~2 문장) |
| 답변 톤 | 친근·즉답 |
| 비공개 정보 | 마진율, 매장 인센티브 |
| RAG 우선순위 | latency 짧게 (1초 이내 답변 시작), citation 짧게 |

**예시 질문:**
- "S25 자급제 얼마예요?"
- "이거 폴드보다 가벼워요?"
- "민트색 재고 있어요?"
- "할부 36개월 하면 월 얼마?"

### P2 — B2B 영업 (기업 영업 · 단체 도입 · 제안서)

| 항목 | 내용 |
|---|---|
| 환경 | *제안서 작성. 단가표·DeX 시연·관리 솔루션 검토. 시간 여유 있음.* |
| 자주 받는 질문 | "100대 단가?", "DeX 무선 지원 모델?", "관리 솔루션 Knox 호환?", "수리 정책?", "기업 보안 인증?" |
| **가장 필요한 정보** | DeX·Knox·보안 인증 (KCMVP·CC·NIAP), 대량 견적 기준가, 기업용 액세서리 (Tab Book Cover 등), 수리·교체 정책, 임대 가능성 |
| 답변 길이 | 중장문 OK (3~10 문장, 표 환영) |
| 답변 톤 | 격식·전문·근거 |
| 비공개 정보 | 기업 견적 단가, 임대 계약 |
| RAG 우선순위 | accuracy · citation 정확 · 비교표 출력 |

**예시 질문:**
- "Tab S10 Ultra 100대 일괄 도입 시 키보드·S Pen 포함?"
- "Knox Manage 와 어떤 모델 호환?"
- "기업 회원사 수리 우선 처리 정책?"
- "Z Fold6 vs Tab S10+ 출장 임원용 추천?"

### P3 — 본사 마케팅·영업기획

| 항목 | 내용 |
|---|---|
| 환경 | *통계·캠페인 기획. 경쟁사 분석. 시간 여유. PC 환경.* |
| 자주 받는 질문 | "S25 vs iPhone 16 카메라 spec 표", "AP Geekbench 점수", "GfK 점유율 추세", "출시 후 N개월 판매 곡선" |
| **가장 필요한 정보** | 경쟁사 풀스펙, 벤치마크 점수, 시장 점유율, 출시 캘린더, 가격 변동 history |
| 답변 길이 | 표·표·표. 가공된 데이터 선호 |
| 답변 톤 | 데이터 중립 |
| 비공개 정보 | 매출·KPI·재고 (사내 BI 도구 영역) |
| RAG 우선순위 | 완전성 · 출처 명시 · 수치 정확 |

**예시 질문:**
- "S25 Ultra Geekbench 점수 vs iPhone 16 Pro"
- "Galaxy A55 글로벌 판매량 추세"
- "한국 5G 시장 Galaxy 점유율 2024 Q4"

### P4 — 외판·방문판매·콜센터

| 항목 | 내용 |
|---|---|
| 환경 | *전화·방문. 화면 못 보는 경우 음성 only. 30~60초.* |
| 자주 받는 질문 | "월 얼마?", "약정 끝나면 변경 가능?", "지금 사면 사은품?", "가족 결합 할인?" |
| **가장 필요한 정보** | 통신사별 월 납부액, 약정 조건, 사은품·이벤트, 결합 할인 시뮬레이션 |
| 답변 길이 | 매우 짧음 (음성 친화 1~2 문장) |
| 답변 톤 | 친근·간결 |
| 비공개 정보 | 통신사 보조금표 (수시 변동) |
| RAG 우선순위 | 정확한 가격 + 갱신 시점 명시 |

**예시 질문:**
- "S25 KT 36개월 약정 월 얼마?"
- "가족 4명 결합하면?"
- "지금 사은품 뭐 줘?"

## 4. 페르소나별 corpus 매핑

지금 코퍼스 (97 chunks) vs 페르소나별 *진짜* 필요한 데이터:

| 페르소나 | 현재 corpus 로 답 가능 | 추가 필요 (공개 정보 한도) |
|---|---|---|
| P1 매장 | 스펙·색상·USD 가격 | **한국 자급제·통신사 출고가, 1줄 셀링 포인트, 색상별 출시일** |
| P2 B2B | DeX·일부 액세서리 | **Knox 호환 모델, 보안 인증, 대량 견적 기준 (공개 가격)** |
| P3 본사 | 스펙 풀시트 (lineup csv) | **경쟁사 (iPhone/Pixel/Xiaomi) 풀스펙, AP 벤치, 글로벌 판매 추세 (공개)** |
| P4 외판 | 거의 못 답함 | **통신사별 공개 출고가, 약정 옵션, 사은품 이벤트 (변동성 큼)** |

**비공개 = 절대 수집 안 함:** 마진율, 매장 KPI, 통신사 보조금 표, 기업 견적 단가, 가족결합 할인율.

## 5. 페르소나별 dataset 분포 (10K)

전제: **분포는 페르소나 비중 가설** 에 따라 조정.
*작업 가설 비중* — 실제 사내 트래픽 측정 후 보정 필요:

| 페르소나 | 비중 (가설) | 10K 중 | 질문 특성 |
|---|---|---|---|
| P1 매장 | 50% | 5000 | 짧은 질문, 가격/색상/할부 중심, 한국어 구어 ("얼마?", "재고?") |
| P2 B2B | 25% | 2500 | 긴 질문, 기능 비교, 정책, 격식 ("도입 시", "호환 여부") |
| P3 본사 | 15% | 1500 | 비교·통계·경쟁사 ("vs", "점유율", "벤치마크") |
| P4 외판 | 10% | 1000 | 음성형 짧은 질문, 통신사·약정 ("월 얼마?", "약정 끝나면?") |

**난이도 분포 (페르소나 무관 cross-cut):**
| 난이도 | 비율 | 정의 |
|---|---|---|
| Easy (정확매칭) | 30% | 키워드 그대로 corpus 에 존재 |
| Medium (paraphrase) | 30% | synonym, 줄임말, 구어 |
| Hard (negation/cross-cat/multi-hop) | 25% | 기능 부재 확인, 비교, 조건 결합 |
| N/A (코퍼스 외) | 10% | "모른다" 응답 검증 |
| Adversarial (오타·spoof) | 5% | "S25울트라" 같은 비공식 표기 |

## 6. 10K 생성 파이프라인 (페르소나 기반)

```
페르소나 1~4 + 카테고리 6개 (foldable/A/Tab/flagship/buds/watch)
        ↓
페르소나 × 카테고리 × 난이도 × 질문 의도 = 매트릭스 셀
        ↓
각 셀당 N개 생성 (총합 10K)
        ↓
   ┌─────────────────────────────────┐
   │ Template (60%) — 결정적          │
   │   • corpus fact + 페르소나 어휘  │
   │   • "P1 + foldable + easy + 가격"│
   │     → "Z Fold6 자급제 얼마예요?"│
   ├─────────────────────────────────┤
   │ LLM paraphrase (30%) — 다양화    │
   │   • template 결과를 페르소나     │
   │     말투로 rewrite                │
   ├─────────────────────────────────┤
   │ LLM 자연어 생성 (10%) — naive    │
   │   • "P1 매장 직원 입장에서       │
   │     자주 할 질문 N개 만들어줘"   │
   └─────────────────────────────────┘
        ↓
JSONL 저장 + stratified sample500 추출
        ↓
재현 가능 (seed 고정), 결정적, 비용 한정
```

## 7. 데이터 흐름 (페르소나 인식 RAG)

```
[사용자 질문]
        ↓
(1) Persona Classifier (선택) ── LLM 1콜
        ├─ "이거 얼마예요?" → P1 매장
        ├─ "100대 견적" → P2 B2B
        ├─ "iPhone 16 대비" → P3 본사
        └─ "월 얼마" → P4 외판
        ↓
(2) Category Classifier ── 기존 Stage 3
        ↓
(3) Retrieval (dense + BM25)
        + filter(persona_tier, category)
        ↓
(4) Reranker
        ↓
(5) Generation
        - prompt 에 페르소나 명시
        - P1 → "1~2 문장 즉답"
        - P2 → "표 + 격식"
        - P3 → "수치 + 출처"
        - P4 → "음성 친화 단답"
        ↓
[답변 + citation]
```

## 8. 확인 방법 — 페르소나 가설 보정

이 문서는 **가설** 이다. 다음 절차로 보정:

1. **사내 인터뷰 5명 × 페르소나** — 30분씩, 자주 받는 질문 top 10
2. **수집된 100개 질문** 을 dataset 에 ground-truth 로 흡수
3. 분포·난이도 가중치 재조정
4. **3개월 후 실제 챗봇 로그** 로 분포 검증

인터뷰 없이는 이 문서의 페르소나 비중 (50/25/15/10) 은 *내 추측* 이다.

## 9. 연습 문제

### 문제 1 (쉬움)

P1 매장 직원과 P3 본사 기획 모두 "S25 카메라" 라고 질문했다. 같은 답을
주는 것이 맞나? 다르다면 어떻게 다르게 답해야 하나? 2개 이상 차이점 답하라.

> **힌트:** 답변 길이, 답변 톤, 포함 정보 (가격 vs 벤치마크).

### 문제 2 (중간)

P2 B2B 영업이 "Tab S10 Ultra 100대 도입 견적" 이라고 물었다. 우리 corpus 에는
공개 USD 가격만 있다. RAG 가 어떻게 응답해야 하는가? 답변 본문 + 메타 정보
(citation 와 disclaimer) 를 직접 1~2 문장씩 작성하라.

> **힌트:** "기업 견적은 공개 단가 외 변수가 큼. 본 가격은 공개 시작가
> 기준이며, 대량 도입 시 별도 견적 필요" 패턴.

### 문제 3 (어려움)

10K dataset 중 P1 매장 5000 질문에서 평균 MRR = 0.92, 평균 답변 길이가
8 문장이다. 이걸 production 으로 출시하면 매장 직원 만족도는 어떻게 될까?
**MRR 만 좋아진 게 만족도와 직결되지 않는** 이유 3가지를 답하라.

> **힌트:** P1 의 답변 환경 (고객 앞), 정보 과잉의 비용, latency, 음성 변환 가능성.

- [ ] 페르소나 비중 (50/25/15/10) 유지 / 조정? 인터뷰 결과로.
- [ ] 비공개 정보 (마진·결합 할인) 의 경계 — RAG 가 "내부 시스템 참조" 라고 redirect?

- [ ] Corpus 재수집 우선순위: P1 (한국 출고가) vs P3 (경쟁사 스펙) 중 어디 먼저?
