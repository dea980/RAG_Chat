## 8. 학습 메모 — 이 세션이 가르친 것

- **멱등성이 비동기보다 먼저** — 동기 ingest 가 idempotent 한 후에야
  Celery/큐가 안전. 88청크 누적 사고가 그 증거.
- **Plugin registry + side-effect import** — 새 포맷 = loader 파일 1개 +
  데코레이터 한 줄. core 안 건드림.
- **결정론적 청크 id** — Chroma `add_documents` 가 자동 upsert. 외부 시스템
  정합성을 sink 가 책임짐.
- **안정 키 (`upload://name`)** — 임시 파일의 변동성을 의미 식별자로 추상화.
  Source URI scheme 으로 확장 가능 (s3://, gdrive:// 등).
- **Optional 인자 + default** — pipeline 한 곳에서 dispatch. 호출처 단순.
- **"정말 필요한가?" 푸시백** — 트리거 없는 인프라 추가는 보류가 정답. 메모리에
  feedback 으로 저장됨.
- **Multi-agent flow** — 코드는 Codex/다른 Claude, 문서·일관성은 Claude Code.
  새 코드 들어오면 통합 doc 작성 + 불일치 노트.
