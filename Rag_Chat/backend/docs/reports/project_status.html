01 방금 마무리한 작업 — Provider 스위칭

Chat LLM 과 임베딩을 분리하고, 프론트엔드에서 provider 조합을 골라 쓸 수 있게 정리했습니다.

① Chat LLM provider 확장

ProviderManager 가 reasoning / generation 모델을 독립적으로 해석합니다. 지원 provider:

  • gemini (기본값)
  • qwen · openrouter
  • ollama — 로컬 OpenAI 호환 API
  • huggingface — Inference Endpoint / TGI

Ollama·HF 모두 OpenAI 호환 엔드포인트를 통해 ChatOpenAI 로 연결됩니다.

② 임베딩은 시스템 스코프로 분리

임베딩은 세션이 아니라 시스템 단위 설정입니다. 표시는 chat LLM 과 분리됩니다.

  • 지원: gemini, openrouter
  • get_embedding_config() 가 requires_reindex: true 를 노출

⚠️ 임베딩을 바꾸면 기존 Chroma 벡터 DB를 반드시 재구축해야 검색 품질이 유효합니다.

③ 프론트엔드 Provider 프리셋 (Streamlit 사이드바)

frontend/app.py 사이드바의 Provider Preset 셀렉트박스로 세션별 조합을 전환합니다:

04 다음 할 일 — 환경 설정 가이드

① Ollama 로컬 모델 ✅ 모델 확인 + .env 반영 완료

로컬 설치 모델: qwen3.6 (23GB), gemma4 (9.6GB). llama3.1은 미설치 → 필요 시 ollama pull llama3.1. .env는 OLLAMA_MODEL=qwen3.6으로 설정됨.

# 데몬 실행 (모델은 이미 로컬에 있음)
ollama serve

# .env — provider 만 ollama 로 전환하면 즉시 사용 가능
REASONING_PROVIDER=ollama
GENERATION_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434/v1
OLLAMA_MODEL=qwen3.6   # 또는 gemma4

② Hugging Face — OpenAI 호환 엔드포인트 필요 ⏸️ 나중에 설정 (담당자 직접)

엔드포인트는 추후 직접 준비 예정. 단순 모델명만으로는 부족하며 Inference Endpoint / TGI 같은 OpenAI 호환 엔드포인트가 있어야 합니다. (아래는 참고용 형식)

REASONING_PROVIDER=huggingface
GENERATION_PROVIDER=huggingface
HUGGINGFACE_API_KEY=...
HUGGINGFACE_BASE_URL=https://....endpoints.huggingface.cloud/v1
HUGGINGFACE_MODEL=meta-llama/Llama-3.1-8B-Instruct

③ 임베딩은 별도 관리 (변경 시 재인덱싱)

# 임베딩 변경 → 기존 Chroma 벡터 DB 재구축 필수
EMBEDDING_PROVIDER=gemini
EMBEDDING_MODEL=models/text-embedding-004

④ 프론트엔드에서 선택

Streamlit 사이드바 Provider Preset 에서 Ollama Only / OpenRouter Only 등을 골라 세션 단위로 전환.

05 환경 변수 통합 (이번 세션)

.env 를 단일 source of truth 로 통합하고 .env.example 을 제거했습니다.

  • 병합 — .env.example 에만 있던 RERANKER_MODEL/TOP_N/TOP_K/DEVICE, OLLAMA_*, HUGGINGFACE_* 키를 겹치지 않게 .env 에 추가
  • 유지 — 이미 있던 키(REASONING_PROVIDER/GENERATION_PROVIDER=openrouter 등)는 기존 값 보존
  • 제외 — EMBEDDING_MODEL 은 추가하지 않음 (.env 의 GOOGLE_EMBEDDING_MODEL=models/gemini-embedding-001 과 값 충돌 방지)
  • 삭제 — git 추적되던 .env.example 제거
  • .gitignore — .env.example 무시 추가 (.env 는 기존부터 무시됨)

결과: .env / .env.example 모두 git 에 올라가지 않으며, 환경 설정은 .env 한 곳에서 관리됩니다.

  • Single node — HA / auto-scale 미설계
