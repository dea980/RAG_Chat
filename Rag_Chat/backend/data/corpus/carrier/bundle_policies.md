## 7. 갱신 정책

- **공시지원금**: 주 1회 (방통위 갱신 주기) — `manifests/lineage.jsonl` 에 `weekly_refresh=true` 표시 권장
- **출고가**: 신규 모델 출시 시점 + 분기 1회 확인
- **결합 상품 카테고리**: 신규 상품 출시 시 (보통 분기 1회)

## 8. 금지 — 챗봇 응답에 절대 포함 금지

1. "가족결합 시 X% 할인" — *정확 할인율은 사내 계산. 페르소나 답변 금지.*
2. "이번 달 추가지원금은 N만원" — 유통점 변동, 비공개.
3. "매장 인센티브 / 영업 KPI" — 비공개.
4. 통신사 사내 자료에서 캡쳐한 보조금표 — 출처 위반.

위 4종은 ingest 시 moderation 규칙 `audience_tier=carrier` 라 해도 차단 대상으로 등록할 것.
