Galaxy S25 시리즈 자주 묻는 질문

본 FAQ 는 공개된 실제 사양 (gsmarena.com / wikipedia) 기반으로 작성됨. 출시일·가격·환율은 변동 가능.

1. 출시 및 가격

1.1 Galaxy S25 시리즈는 언제 발표·출시되었나요?

2025년 1월 22일 Galaxy Unpacked 행사에서 발표되었으며, 2025년 2월 7일 (gsmarena 기준 2월 3일) 정식 출시되었습니다.

1.2 각 모델 시작가는 얼마인가요?

S25 기본형은 USD 434.95 (128GB), S25 Plus 는 USD 579.95 (256GB), S25 Ultra 는 USD 737.93 (256GB) 입니다.

2. 카메라

2.1 S25 와 S25 Ultra 의 카메라 차이는?

S25 / S25 Plus 는 50MP 메인 + 10MP 3배 망원 + 12MP 초광각 트리플 구성입니다. S25 Ultra 는 200MP 메인 + 50MP 5배 페리스코프 + 10MP 3배 망원 + 50MP 초광각의 쿼드 구성으로, 광학 줌이 5배까지 가능합니다.

2.2 8K 동영상 녹화를 지원하나요?

세 모델 모두 8K@24/30fps 녹화를 지원합니다. 4K 는 30/60fps, 1080p 는 30/60/120/240fps 지원합니다.

3. 디스플레이

3.1 화면 보호 유리는 어떻게 다른가요?

S25 와 S25 Plus 는 Corning Gorilla Glass Victus 2 (Mohs level 5) 를 사용합니다. S25 Ultra 는 새로운 Corning Gorilla Armor 2 (Mohs level 6) 에 DX 반사 방지 코팅이 추가됩니다.

3.2 최대 밝기는 얼마인가요?

세 모델 모두 피크 밝기 2600 nits 를 지원합니다.

4. 배터리·충전

4.1 배터리 용량과 충전 속도는?

S25 기본형은 4000mAh / 25W 유선 충전, S25 Plus 는 4900mAh / 45W, S25 Ultra 는 5000mAh / 45W 입니다. 모두 15W Qi2 Ready 무선 충전과 4.5W 역방향 무선 충전을 지원합니다.

4.2 PD3.0 45W 충전 시 30분에 얼마나 충전되나요?

S25 Plus 와 S25 Ultra 는 PD3.0 45W 로 30분에 약 65% 충전됩니다. S25 기본형 (25W) 은 30분에 약 50% 충전됩니다.

5. 소프트웨어

5.1 출시 OS 버전은?

Android 15 기반 One UI 7 로 출시되었습니다.

5.2 업데이트 보장 기간은?

OS 메이저 업그레이드 7회, 보안 패치 7년이 보장됩니다.

6. 연결성

6.1 어떤 무선 통신을 지원하나요?

5G Sub-6 (미국 모델은 mmWave 포함), Wi-Fi 7 (tri-band), Bluetooth 5.4 (LE), UWB (Ultra Wide Band) 를 지원합니다.

6.2 SIM 구성은?

국제판: Nano-SIM + Nano-SIM + eSIM + eSIM (동시 2개 활성). 미국판: Nano-SIM + eSIM + eSIM. 중국판: Nano-SIM + Nano-SIM.

7. 디자인

7.1 무게 비교는?

S25 162g, S25 Plus 190g, S25 Ultra 218g.

7.2 Ultra 의 프레임 소재는?

Grade 5 티타늄 프레임을 사용합니다. S25 와 S25 Plus 는 Armor aluminum 2 입니다.
