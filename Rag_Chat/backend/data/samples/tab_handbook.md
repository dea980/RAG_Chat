# Samsung Galaxy Tab 라인업 핸드북 (B2B 제안서용)

> 출처: gsmarena.com / en.wikipedia.org (공개 스펙 페이지 기준)
> 본 문서는 영업·제안서 작성팀이 자주 묻는 태블릿 4종 — Tab S10 Ultra, Tab S10+, Tab S9 FE, Tab A9+ — 의 공개 사양을 정리한 것이다.
> 가격은 출시 시점 또는 현행 시장가 추정. 정확한 견적은 samsung.com / 총판 채널로 재확인 필요.
> **N/A 표기는 "공개 스펙 페이지에 명시되지 않음"을 뜻한다. 추측 금지.**

## 1. 시리즈 개요

삼성 태블릿은 크게 세 트랙으로 나뉜다:

| 트랙 | 대상 | 모델 (본 문서) | 핵심 차별점 |
|---|---|---|---|
| **프리미엄 (Tab S 플래그십)** | 임원·디자인·필드 영업·키오스크 | Tab S10 Ultra / S10+ | Dynamic AMOLED 2X, Dimensity 9300+, S Pen 기본, IP68, DeX |
| **중급 (Tab S FE)** | 사내 교육·매장 디스플레이·콜센터 | Tab S9 FE | 90Hz LCD, Exynos 1380, S Pen 기본, IP68, 합리적 가격 |
| **보급형 (Tab A)** | 키오스크·재고관리·창고 PDA 대체 | Tab A9+ | LCD, Snapdragon 695, S Pen 미포함, 저단가 대량 배포 |

B2B 의사결정 핵심 질문은 항상 같다 — **(1) S Pen 이 박스에 들어 있는가?
(2) Book Cover Keyboard 는 별매인가? (3) DeX 로 데스크탑 모드를 쓸 수 있는가?
(4) 5G 모델이 있는가? (5) microSD 슬롯이 있는가?**
본 문서는 이 다섯 가지를 모든 모델에서 표기한다.

## 2. Galaxy Tab S10 Ultra (플래그십·대화면)

### 2.1 디스플레이
- 크기: 14.6인치
- 패널: Dynamic AMOLED 2X
- 해상도: 1848 x 2960 (~239 ppi)
- 주사율: 120Hz
- 종횡비: 16:10

### 2.2 프로세서·메모리
- AP: MediaTek Dimensity 9300+ (4nm)
- CPU: 1x Cortex-X4 3.4GHz + 3x Cortex-X4 2.8GHz + 4x Cortex-A720 2.0GHz
- GPU: Immortalis-G720 MC12
- RAM: 12GB / 16GB
- 저장: 256GB / 512GB / 1TB + **microSDXC 슬롯 지원**

### 2.3 카메라
- 후면 메인: 13MP f/2.0, 26mm wide, AF
- 후면 초광각: 8MP f/2.2
- 전면 듀얼: 12MP f/2.2 wide + 12MP f/2.4 120° ultrawide (화상회의용)

### 2.4 배터리·충전
- 용량: 11,200mAh
- 유선: 45W PD
- 무선 충전: 미지원

### 2.5 디자인·내구성
- 크기: 326.4 x 208.6 x 5.4 mm
- 무게: 718g (Wi-Fi) / 723g (5G)
- 프레임: Aluminum Armor + 글래스 전면
- 방수·방진: **IP68 (1.5m 30분)**
- 색상: Moonstone Gray, Platinum Silver

### 2.6 액세서리·생산성
- **S Pen: 박스 기본 포함** (2.8ms latency, Bluetooth 연동)
- **Book Cover Keyboard: 별매** (자석식 부착 + 전용 키보드)
- **DeX: 지원** (무선 Samsung DeX 가능 — 외부 모니터로 데스크탑 모드)

### 2.7 연결성
- Bluetooth 5.3, Wi-Fi 7 (a/b/g/n/ac/6e/7)
- USB Type-C 3.2
- **5G 모델 존재** (SM-X926B / SM-X926N) — Wi-Fi 전용 모델과 별개로 판매

### 2.8 OS·업데이트
- 출시 시: Android 14 + One UI 6.1
- 업데이트 보장: OS 7년 + 보안 패치 7년 (Tab S10 라인 공통)

## 3. Galaxy Tab S10+ (플래그십·휴대형)

### 3.1 디스플레이

- 유선: 45W

### 3.5 디자인·내구성
- 크기: 285.4 x 185.4 x 5.6 mm
- 무게: 571g (Wi-Fi) / 576g (5G)
- 프레임: Enhanced Armor aluminum
- 방수·방진: **IP68 (1.5m 30분)**
- 색상: Moonstone Gray, Platinum Silver

### 3.6 액세서리·생산성
- **S Pen: 박스 기본 포함** (2.8ms latency, Bluetooth 통합)
- **Book Cover Keyboard: 별매** (자석식 매그네틱 커넥터)
- **DeX: 지원** (무선 Samsung DeX)

### 3.7 연결성
- Bluetooth 5.3, Wi-Fi 6E (tri-band)
- USB Type-C 3.2 (자석식 커넥터 호환)
- **5G 모델 존재** (SM-X826B)

### 3.8 OS·업데이트
- 출시 시: Android 14 + One UI 6.1
- 업데이트 보장: OS 7년 + 보안 패치 7년

## 4. Galaxy Tab S9 FE (중급·합리적 선택)

### 4.1 디스플레이
- 크기: 10.9인치
- 패널: PLS LCD (TFT) — **AMOLED 가 아닌 점 주의**
- 해상도: 1440 x 2304 (~249 ppi)
- 주사율: 90Hz

### 4.2 프로세서·메모리
- AP: Samsung Exynos 1380 (5nm)
- CPU: 4x Cortex-A78 2.4GHz + 4x Cortex-A55 2.0GHz
- GPU: Mali-G68 MP5
- RAM: 6GB / 8GB
- 저장: 128GB / 256GB + **microSDXC 최대 1TB**

### 4.3 카메라
- 후면: 8MP AF (단일)
- 전면: 12MP f/2.4 120° ultrawide

### 4.4 배터리·충전
- 용량: 8,000mAh
- 유선: 45W PD
- 무선 충전: 미지원

### 4.5 디자인·내구성
- 크기: 254.3 x 165.8 x 6.5 mm
- 무게: 523g
- 프레임: 알루미늄 유니바디
- 방수·방진: **IP68 (1.5m 30분)** — FE 등급에서도 유지되는 장점
- 색상: Mint, Gray, Lavender, Silver

### 4.6 액세서리·생산성
- **S Pen: 박스 기본 포함** (Tab S 시리즈 전통)
- **Book Cover Keyboard: 별매** (S9 FE 전용 액세서리)
- **DeX: 미확인 (출처에서 명시되지 않음 — 사용자 매뉴얼 재확인 필요)**

### 4.7 연결성
- Bluetooth 5.3, Wi-Fi 6 (a/b/g/n/ac/ax dual-band)
- USB Type-C 2.0 (S10 시리즈의 3.2 대비 다운그레이드 주의)
- **5G 모델 존재 여부: Wikipedia 사양 페이지에선 미명시. 한국 시장에는 5G 변형이 별도 SKU 로 판매됨 — 견적 시 모델 코드(SM-X516B 등) 확인 필요**

### 4.8 OS·업데이트
- 출시 시: Android 13 + One UI 5.1.1
- 업데이트 보장: OS 4년 + 보안 패치 5년 (FE 라인 공통)

## 8. DeX (데스크탑 모드) 요약

**Samsung DeX 는 태블릿을 외부 모니터에 연결하면 데스크탑 비슷한 멀티윈도우 UI 로 전환되는 기능이다.**
영업 사원이 고객사에서 모니터·키보드만 빌려 즉석 프레젠테이션·문서 작업을 할 수 있다.

- Tab S10 Ultra / S10+: **무선 DeX 지원** (HDMI 케이블 또는 미라캐스트로 무선 연결)
- Tab S9 FE: 공개 스펙에서 DeX 항목 N/A — Samsung 매뉴얼/지원 페이지로 재확인 권장
- Tab A9+: DeX **미지원**
