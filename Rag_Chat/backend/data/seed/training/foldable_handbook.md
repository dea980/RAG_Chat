## 1. 시리즈 개요

Samsung Galaxy Z 시리즈는 삼성전자의 폴더블 플래그십 라인업이다.
- **Z Fold** 계열: 7.6인치 내부 디스플레이를 펼치는 북-폴드 (book-fold) 형태. 태블릿+폰 융합.
- **Z Flip** 계열: 위아래로 접는 클램쉘 (clamshell) 형태. 작아진 휴대성에 초점.
- 본 핸드북은 2024년 7월 출시된 **Z Fold6 / Z Flip6** (6세대) 와 2023년 8월 출시된 **Z Fold5** (5세대, 직전 세대) 를 다룬다.

세 모델 공통:

- **방수 보호**: IP48 (Z Fold6/Flip6) 또는 IPX8 (Z Fold5) — 물에는 강하나 미세 분진(<1mm) 차단 등급은 6세대에 처음 도입
- **OS at Launch**: Android 14 + One UI 6.1.1 (Z Fold6/Flip6), Android 13 + One UI 5.1.1 (Z Fold5)
- **USB**: USB Type-C 3.2 (DP/OTG)
- **Bluetooth**: 5.3
- **microSD**: 미지원 (전 모델)
- **외장 색상 라인업**: 온라인 한정 색상 별도 존재 가능

> 업데이트 보장 정책의 변경점: Z Fold5 는 출시 시 "4 OS + 5 보안" 정책이었으나, Z Fold6/Flip6 는 삼성의 7년 정책 (S24 이후) 으로 확장.

## 2. Galaxy Z Fold6

- 망원: 10MP f/2.4, 66mm, 3배 광학 줌, PDAF, OIS
- 페리스코프: 없음
- 커버 셀피: 10MP f/2.2, 24mm

### 2.4 메모리·저장

## 5. 폴더블 특화 요소

### 5.1 힌지
- Z Fold5 부터 Flex Hinge 채택 → 펼쳤을 때 디스플레이 평탄도, 접었을 때 갭 감소
- Z Fold6 는 동일 Flex Hinge 유지하면서 알루미늄 프레임 매트 처리·모서리 각도 변경

### 5.2 언폴드 디스플레이 보호
- 외부 (커버 + 후면): Corning Gorilla Glass Victus 2
- 내부 (메인): UTG (Ultra-Thin Glass) + 플라스틱 보호 레이어 — 외부 글래스보다 취약, 손톱·필기구 자국 가능

### 5.3 S Pen 지원
- **Z Fold6 / Z Fold5: S Pen Fold Edition 지원** (별매, 본체 내장 슬롯 없음 — 별도 케이스 사용)
- **Z Flip6: S Pen 미지원** (Flip 라인은 전 세대 모두 미지원)

### 5.4 IP 등급 변화
| 세대 | 등급 | 의미 |
|---|---|---|
| Z Fold5 / Flip5 | IPX8 | 물 1.5m 30분만 보장, 분진 등급 없음 |
| Z Fold6 / Flip6 | IP48 | 분진 1mm 이상 차단 추가 (해변·공사장 등) |
