# 연차 휴가 운영 지침 (합성 샘플)

> [중요] 본 지침은 markdown heading splitter 단위 테스트용 합성 데이터입니다.
> 실제 사내 규정·법령이 아닙니다.
>
> 실제 연차 관련 법령: [근로기준법 제60조](https://www.law.go.kr/법령/근로기준법)
> 실제 표준 취업규칙: [고용노동부 2026년판 HWP](https://www.moel.go.kr/policy/policydata/view.do?bbs_seq=20260200740)

## 1. 적용 대상

본 지침은 회사와 근로계약을 체결한 모든 정규직 및 계약직 직원에게 적용된다.

## 2. 연차 발생 기준

### 2.1 입사 1년 미만
- 매월 개근 시 익월 1일 발생
- 최대 11일까지 발생 가능

### 2.2 입사 1년 이상
- 매년 1월 1일에 15일 일괄 부여
- 근속 3년부터 2년마다 1일씩 가산
- 최대 한도: 25일

### 2.3 근속 연수별 연차 일수

| 근속 연수 | 연차 일수 |
|---------|---------|
| 1년~2년 | 15일 |
| 3년~4년 | 16일 |
| 5년~6년 | 17일 |
| 7년~8년 | 18일 |
| 9년~10년 | 19일 |
| 11년 이상 | 20일~최대 25일 |

## 3. 사용 방법

### 3.1 신청 절차
1. 연차 사용 7일 전까지 사내 시스템에 신청
2. 직속 상사 승인 후 인사팀 확정
3. 긴급한 경우 당일 신청 가능 (관리자 사후 승인)

### 3.2 분할 사용
- 반차: 오전 (9~13시) 또는 오후 (14~18시)
- 시간 단위: 1시간 단위로 사용 가능 (연 16시간 한도)

## 4. 연차 사용 권장

### 4.1 의무 사용 일수
연간 부여된 연차의 70% 이상을 사용해야 한다.
70% 미만 사용 시 미사용 연차에 대한 금전 보상은 지급하지 않는다.

### 4.2 권장 사용 기간
- 여름 휴가: 7월~8월 중 연속 5일
- 겨울 휴가: 12월 마지막 주 또는 1월 첫 주

## 5. 미사용 연차의 처리

### 5.1 이월
원칙적으로 미사용 연차는 다음 해로 이월되지 않는다.

### 5.2 수당 지급
회사 사정으로 사용하지 못한 연차에 한해 통상임금의 100%를 수당으로 지급한다.

## 6. 특별 휴가와의 관계

연차와 별도로 다음 특별 휴가가 부여된다.
- 경조사 휴가 (사규 제9조)
- 병가 (사규 제10조)
- 출산휴가 (90일, 별도 법령 준수)

## 7. 문의처

연차 관련 문의는 인사팀 (내선 5500) 으로 연락한다.
